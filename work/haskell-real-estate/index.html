Project overview

A more professional real estate website that also supports practical property-management workflows.

Haskell Real Estate needed a refreshed online presence with updated branding, stronger visuals and functionality that supported both marketing and property management. The project included a redesigned logo, professional photography, background video and a modern website experience.

The website was also built to be useful for renters, property owners and the internal team, with maintenance request submission and rental listing management built into the site experience.

For property management, the website should support trust, available listings and the day-to-day requests people actually need.
