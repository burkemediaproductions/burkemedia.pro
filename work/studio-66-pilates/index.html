Fitness Studio Case Study

Studio 66 Pilates

Website redesign, brand refinement, SEO-focused content and MindBody integration for a Glendora Pilates studio.

Project focus

A polished fitness studio website connected to real class information.

For Studio 66 Pilates, BurkeMedia helped strengthen the digital presence of a Glendora fitness studio through website redesign, brand refinement, SEO-focused content, and MindBody integration.

The project focused on creating a clean, on-brand experience that helped new visitors understand the studio, explore classes and pricing, meet the team, and stay connected with current class information.

  • Industry: Martial Arts & Fitness Studios
  • Website redesign for a polished black and blue studio brand.
  • Logo and dragonfly mark refinement for stronger brand consistency.
  • MindBody-connected class information, instructor details, class descriptions and cancellation status.

Website redesign

A cleaner online experience for clients, visitors and the studio team.

The Studio 66 Pilates website was redesigned to feel more polished, more useful and more connected to the way the studio actually operates.

Brand presence

Clean black and blue visual direction

The site supported Studio 66 Pilates with a refined black and blue look that felt modern, focused and aligned with the studio’s identity.

Studio content

Classes, pricing and team information

The website was structured to present classes, pricing options, team members, instructors and the story behind the studio in a clearer way.

SEO content

Glendora Pilates visibility

SEO-focused content, including About page copy, helped explain the heart of the studio while supporting search visibility for Pilates in the Glendora area.

Brand refinement

Making the Studio 66 Pilates identity easier to use across the site.

BurkeMedia also worked on the studio’s logo and brand presentation, including refining the dragonfly from the original logo so it could be used more clearly across the website and marketing materials.

This gave the studio a stronger, more consistent visual identity while still preserving a recognizable brand element that already mattered to the business.

Visual identity

Dragonfly mark refinement

The dragonfly became a cleaner brand asset that could support the website, visual system and future marketing in a more consistent way.

MindBody integration

Connecting the website to the studio’s real class and business information.

A major part of the project was integrating the website with MindBody so the site could stay more connected to Studio 66 Pilates’ actual schedule and operations.

The website included custom structures for classes, pricing options and team members, allowing studio content to be organized in a way that was both customer-friendly and easier to manage.

  • Class information pulled into the website experience.
  • Upcoming class dates and instructor information.
  • Class descriptions, levels, types and cancellation status.
  • Less duplicate manual updating between business systems and the website.

Project impact

A beautiful, organized and practical online presence.

The work for Studio 66 Pilates combined website redesign, logo refinement, brand presentation, SEO-focused content, custom WordPress structure and MindBody integration. The goal was to help clients learn about the studio, explore classes and pricing, meet the team and stay connected with current class information.
